# 合成大西瓜：需求与方案

## 玩法

未登录就可以玩。画面是一只开口的木盒，水果从盒口落下。碰撞体全部是圆，每一级的半径固定，不随图片改变。

两个相同级别的水果碰到一起，合成下一级，并加上这一级的分数。盒口有一条危险线，水果停在线以上约 1.5 秒就结束本局。最高分会留下。

十一级从先出现到最后是：樱桃、草莓、葡萄、橙子、柿子、苹果、梨、桃子、菠萝、蜜瓜、西瓜。新掉落的水果只在前五级里随机。西瓜不能再合成。

分数按合成出的那一级计算：1、3、6、10、15、21、28、36、45、55、66。

## 登录

登录和注册放在游戏里的设置侧栏，没有单独页面。

账号用用户名和密码。密码只存 scrypt 哈希。登录成功后浏览器拿到一张 `HttpOnly` cookie，里面是随机的 session token；数据库的 `sessions` 表把 token 的哈希对应到 `player_id`。之后每次读存档、写存档、上传素材，接口都用这张 cookie 查出是哪一位玩家。

没有配置 `DATABASE_URL` 时，登录按钮会说明数据库还没接上，基础游戏照常可玩。存档先写在这台浏览器的 `localStorage`。登录且数据库可用时，落子、合成、结束和离开页面会把快照写到 `player_saves`。打开游戏时如果服务器的 `updated_at` 更新，就用服务器的快照。

## 登录后的自定义

设置里可以替换任意一级的图片，也可以上传一段合成音效。没替换的级别继续用内置画法，没上传音效就用内置的一声轻弹。

图片接受 PNG、JPEG、WebP，单张不超过 1MB。音频接受 MP3、WAV、OGG、WebM，不超过 2MB。文件内容存在 Postgres 里，和账号同一套库，不另接对象存储。

图片画在该级固定的圆内，居中铺满，圆外裁掉。

合成音效用 Web Audio 播放。倍速按合成结果计算：

```text
倍速 = 1 - 0.3 × (结果级别 - 1) / 9
```

合成出草莓是 1.0 倍，合成出西瓜是 0.7 倍。倍速会同时把音高拉低、把时长拉长。掉落和碰壁不播放这段音效。

## 接口

| 路径 | 作用 |
| --- | --- |
| `POST /api/auth/register` | 注册并写入 session cookie |
| `POST /api/auth/login` | 登录 |
| `POST /api/auth/logout` | 删除 session 并清掉 cookie |
| `GET /api/auth/me` | 当前玩家；同时说明数据库是否已配置 |
| `GET /api/save`、`PUT /api/save` | 读取或覆盖游戏快照 |
| `GET /api/custom` | 已上传的级别和是否有音效 |
| `GET/POST/DELETE /api/custom/image/[stage]` | 读取、上传、移除某一级图片 |
| `GET/POST/DELETE /api/custom/audio` | 读取、上传、移除音效 |

这些接口是 `app/api` 下的路由函数。部署到 Vercel 后，有请求才启动，返回后结束。

## 环境变量

```text
DATABASE_URL=postgresql://...
```

使用 Neon 的 pooled 连接串，配在 Vercel 项目环境变量和本地 `.env.local`。建表语句见 `doc/schema.sql`。
